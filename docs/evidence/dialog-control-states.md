# Menu, dialog and Home control states

Chromium at 1720 × 1050. Both runs use synthetic projects and local folders. The audit covers the Home project grid, its project menu, active menus in the editor, the clip versions popover, New project, Settings, the shortcut sheet, the folder browser, and toast dismissal. Shortcut entries and separators are static. A menu command's shortcut stays visible in the key column.

The before build is `af5c6f07`. The after build is based on `9b008b13`. Press is captured before release. Menu rows are reached by keyboard focus while their menu remains open.
